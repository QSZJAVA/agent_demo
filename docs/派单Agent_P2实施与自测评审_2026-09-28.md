## 2. 关键行为

### 发布与回滚

- 目录编辑保留现有“已发布定义修改立即生效”的行为。灰度比例主要用于新报表准入，不是同一报表两份 SQL 配置同时执行。
- 新目录建议先创建草稿，在灰度页设置比例，再发布；扩大到 100% 后全部有权限用户可见。灰度不会授予原本没有的报表权限。
- 策略保存和回滚均携带当前版本；并发提交只有一个成功，其余返回 409。回滚生成新版本，不把版本号倒退。
- 目录回滚重新检查查询配置和当前已发布规则的字段兼容性，并准确恢复原来的空负责人、空生效时间等可空字段。
- 规则灰度以公司为单位：发布公司专属规则，其他公司继续通配规则；停用专属规则恢复通配，或在规则页回滚历史版本。
- 解析策略与样本变更、目录或别名变更、模型配置变化，默认一分钟内触发回归；失败记录保存在数据库并写警告日志，可在评估页检查。平台未代替业务方决定真实样本的验收阈值。

### 数据治理

- 默认对话、结果、运营审计留存 365 天，指标 90 天；管理员可在 1～3650 天范围调整。
- 会话删除先保存请求和删除标记、隐藏会话，再分批移除消息与消息事件、删除 Redis 记忆。迟到的日志不再补写，迟到的记忆写入会再次检查删除标记。
- 执行中、待核对、明确失败待处理、活跃预览任务均构成恢复数据保留条件。处理完毕后后续清理轮次继续执行。工作台关闭明确失败任务时记录原因，FAILED 转为 SKIPPED，不发送新的派单请求；UNKNOWN 不允许关闭。
- 会话文本清理与业务结果留存是独立策略。删除会话不立刻删除仍需恢复或审计的派单证据。到期且无未决任务的结果按批清理展示数据、快照明细、相关消息及审计证据。
- 清理保留派单身份键、外部请求号和最终状态等防重信息；不会删除业务系统中的原始报表记录。生产环境的备份、外部日志平台和真实网关数据保留规则仍需由相应系统配置。
- 管理接口按服务器解析的用户身份校验管理员和租户，工作台还检查报表与公司范围。接口路径审计不保存请求查询串、口令或原始请求正文。
