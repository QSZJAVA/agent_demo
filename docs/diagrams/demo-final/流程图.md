## 02 统一任务规划与语义复核

先校验当前焦点、目标、数据域与最终总数，再分别规划和复核；最多三次规划、三次独立判断（含目标重试）。

```mermaid
flowchart TD
  in["本轮完整任务<br/>查询、资格核验或待确认派单"]:::ui
  context["构造有界受控上下文<br/>授权目录、真实对话与可靠对象<br/>授权报表原词与完整任务契约"]:::agent
  model["统一任务规划 → MODEL<br/>AssistantPlan + DispatchDirective<br/>原生 Schema、thinking 关闭"]:::model
  codec{"严格结构解析<br/>字段、类型和枚举，拒绝不可解析输出"}:::guard
  retry["最多两次草稿修正<br/>保留累计草稿、事实及全部差异<br/>合法独立期望保持不变"]:::model
  draft{"程序约束与只读业务预检<br/>身份、原文、范围及当前业务事实<br/>保留契约错误，不应用草稿"}:::guard
  terms{"原文命中的字段词义<br/>授权字符串字段值，最多64项<br/>不提供行身份、草稿或结果全集"}:::guard
  purpose["独立判断目标 → MODEL<br/>结果、数据域、查询承接及最终总数<br/>核对当前焦点，自身可修正一次"]:::model
  review["独立语义复核 → MODEL<br/>原文、受控上下文与词义线索<br/>完整期望、新条件来源及旧条件变化"]:::model
  compare{"校验期望、比较任务与数量<br/>新旧条件逐项核对 / 端点与本轮依据<br/>固定独立总数，漏填与不足同时反馈"}:::guard
  reviewfix["修复复核自身<br/>同时修复前提与证据，不改草稿<br/>与目标判断共用整轮三次预算"]:::model
```
