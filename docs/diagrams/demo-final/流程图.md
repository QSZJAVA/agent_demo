## 02 派单子流程解析与校验

模型不生成SQL或执行请求；脱敏草稿加汇总诊断辅助唯一一次结构修正。

```mermaid
flowchart TD
  in["统一路由判定为派单规划<br/>可派单预览、选择或待确认清单"]:::ui
  context["构造有界受控上下文<br/>当前状态、授权报表及字段元数据"]:::agent
  model["ModelIntentParser → MODEL<br/>V1 Schema、稳定规则与抽象对照<br/>明确凭据阻断、上下文统一脱敏"]:::model
  codec{"IntentCodec 校验<br/>结构、类型、原文证据、禁止条件"}:::guard
  retry["最多一次修正<br/>将具体校验错误交回模型"]:::model
  draft{"SemanticPlanner 草稿校验<br/>覆盖、实体角色与范围一致性"}:::guard
  fail["澄清 / 拒绝 / 失败<br/>不提交部分选择、不自动建单"]:::error
  apply["确定性业务流程<br/>范围 → 快照 → 选择 → 待确认清单"]:::agent
```

## 03 配置字段与实体选择

```mermaid
  scope{"按 reportMentions 限定记录<br/>校验报表权限及当前预览"}:::guard
  fields["FIELDS 条件编译<br/>目录字段白名单、类型、允许操作"]:::agent
  entity["DOCUMENT / DESCRIPTION<br/>或 COUNTERPARTY 稳定客户关联"]:::agent
```

## 06 未知结果、核对与重试
