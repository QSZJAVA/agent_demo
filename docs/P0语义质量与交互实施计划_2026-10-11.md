**P0 语义质量与交互实施计划**

日期：2026-10-11。承接[优化路线](下一阶段优化路线评估_2026-10-11.md)。本轮实现统一任务语义诊断与评估、企业业务词典、条件解释与结构化纠正/澄清；继续使用现有依赖及 `real,mcp`、`agent.semantic.mode=active`、真实模型和认证 HTTP MCP。

| 工作包 | 具体实现 | 验收重点 |
| --- | --- | --- |
| 阶段诊断 | 记录目标、规划、复核的实际调用耗时、有效用量、结构/语义修正、模型与契约指纹；通过已有持久会话事件保存 | 不保存模型原始响应或密钥；缺失计量标为未知；诊断只对本人且当前有权读取的会话开放 |
| 业务词典 | 在已有版本化策略存储中增加独立业务词典，由专用权限边界管理；按数据域、公司、报表配置名称/字段别名、业务说明、单位、枚举、时区与财务年度 | 白名单和类型验证、冲突检查、当前授权、发布版本冲突、历史读取、模型调用期间词典变更拒绝发布旧结果 |
| 解释与条件编辑 | 查询结果保存本轮引用、完整条件、来源与前后差异；编辑请求绑定当前查询引用，转换为明确的本轮要求，再经真实规划、独立复核及业务预检 | 上下界、AND/OR、空值、撤销与继承；跨页旧卡片、刷新、多标签页、撤权、错误后的恢复；不产生派单执行 |
| 结构化澄清 | 模型输出有界选项，服务端核验选项来自当前可见公司、报表或已配置字段值；回复绑定仍有效的澄清引用 | 拒绝伪造值、过期回复及越权选项；保留已经确定的要求；用户选择不等于确认派单 |
| 纠错与评估 | 用户反馈关联具体轮次；版本化语料与评分报告，区分调优/回归/预留语料、失败类型、真实请求及离线复算 | 不自动把用户调整当成模型错误或训练标签；同批失败不被覆盖；自主编写预留语料不冒称业务方独立盲测 |

存储复用现有配置版本、会话消息及权威状态 JSON；不为本轮另建演示库，也不通过新增旧协议解析保持历史数据。本轮计划不需要修改数据库表结构。业务词典采用专用策略键，普通运营策略接口不能绕过其公司/报表权限。词典发布会更新相关报表目录版本，使旧预览和清单继续受到现有版本保护。

实现顺序：先完成词典/诊断及纯逻辑验证，再接入真实模型上下文和严格协议，再实现界面及持久反馈，最后执行受影响模块回归与真实链路验收。所有发现的问题先修共同契约和状态流转，再复验原失败、相邻边界与恢复路径。

测试分为纯程序/前端逻辑、真实数据库与 HTTP MCP、真实模型回放、真实浏览器四层。数据库集成夹具会创建独立测试库，执行前需按 [AGENTS.md](../AGENTS.md) 的数据库规则取得本次明确授权；代码实现及不创建数据库的检查先行推进。真实演示库仍为 `report_demo`，不重置其数据。

具体结果与首次失败在实施完成后的验收记录中填写，本计划不预先声明通过或生产就绪。
