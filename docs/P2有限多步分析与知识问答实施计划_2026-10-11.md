# P2 有限多步分析与业务知识问答实施计划

日期：2026-10-11（Asia/Shanghai）。实现基线为 `2d5d3da`。用户本轮选择实施有限多步分析与业务知识问答；真实工单、外部 ERP、正式身份接入和生产准入暂缓。本文件描述待实现与待验证的范围，完成结论另行归档。

完成更新：2026-10-12 已完成本计划范围的实现与分层自测，见[实现与验收](review/P2有限多步分析与知识问答实现与验收_2026-10-12.md)。下文保留计划时的目标，实际失败、修复、跳过项、最终验证及数据清理以验收报告为准。用户已明确授权本轮隔离数据库创建、写入与清理。

## 交付目标

新增“分析与问答”入口，在用户明确选择的一家公司和一张授权报表内，完成“查询 → 分组统计 → 排名 → 展开相关明细”等有限步骤，并结合可追溯的业务知识回答。复用 P1 完整查询快照、精确计算和认证 HTTP MCP；每个步骤展示来源、完整性和中间结果。支持纯知识问题，也支持从查询工作区选定已有快照开始分析。

自然语言规划与回答均使用实际真实模型链路：`real,mcp`、`agent.semantic.mode=active`、`deepseek-v4.1-flash`、原生 JSON Schema、thinking 关闭。模型接口和 HTTP MCP 配置缺失、超时或输出不可靠时明确失败或澄清；不会从关键词自动生成业务计划。

## 工作包一：有界分析图

- 每次任务最多 6 个步骤、2 次基础查询/快照读取、8 次模型调用，设置单次调用和整轮时间、输入输出体积、并发及保留容量上限。
- 白名单步骤为查询、引用用户选定快照、分组/趋势、行或分组排名、展开排名分组对应的原始明细、两个查询结果对比、知识检索。引用只能指向前面的兼容步骤，不允许循环、自定义代码、SQL、任意工具名或任意网络地址。
- 模型提出完整计划，经结构、字段、类型、范围与引用检查及独立语义复核后执行。修正次数有界；不支持的跨源关联、缺少必要口径、写操作请求等进入澄清。
- 所有数值由确定性程序计算，金额和均值复用 P1 十进制契约。排名来自完整集合，保留并列与币种边界；展开只读取同一基础快照，不重新查询变化后的来源冒充原结果。
- 每步和最终发布前重新核对用户、公司、报表、目录/词典版本与知识版本。分别记录不同基础查询的观测时间，不声称它们属于外部全局事务。

## 工作包二：有来源和版本的业务知识

- 初始可信来源为本系统当前授权目录、字段、业务词典和有效派单规则。规则解释不等于某条单据已符合派单资格，也不等于已经执行。
- 新增管理员维护的制度条目，明确租户、公司、报表、标题、正文、来源名称/可选来源链接、生效日期、失效日期与版本。支持草稿、显式发布、停用及不可变版本历史，版本冲突要求刷新。
- 不预置虚构企业制度。真实制度内容由管理员明确录入；合成制度仅用于隔离测试，并如实标记测试证据范围。
- 先按当前授权与生效期过滤，再进行有界文本检索；当前技术栈内实现检索，不增加向量服务或升级依赖。检索未命中、截断或来源不足必须明确说明。
- 模型回答逐项引用实际来源编号、版本、生效范围和原文片段；程序核对引用身份与原文，另行进行答案依据复核。引用失效、内容冲突或无充分依据时不发布确定性结论。
- 制度正文、目录说明和来源链接都是数据，不能授予权限、修改系统约束、发起网络请求或调用业务写接口。

## 工作包三：任务持久化与页面闭环

- 任务按租户和本人隔离，提交请求号幂等，持久化计划、步骤、证据、实际模型用量与结束原因。页面刷新读取原任务，不重新消耗模型调用。
- 采用短事务认领与令牌租约，外部调用在事务外执行；取消立即撤销回写权，迟到结果不能覆盖终态。进程中断/失租明确结束，重新分析由用户显式发起，不自动重放模型。
- 展示执行进度、确定性统计、有限预览与完整数量、引用原文和未完成原因。明细可分页；切换任务、身份和参数后丢弃旧响应。
- 从查询工作区进入选定快照的分析；知识管理提供表单、版本与发布确认。保留当前业务助手和待确认派单流程的权限、确认、幂等与执行版本保护。

## 工作包四：验证与归档

- 纯逻辑：图结构与引用、步数/体积预算、非法字段/算子、精确计算、分组排名及同源明细、知识检索、引用原文、缺少依据和提示注入边界。
- 隔离数据库与认证 HTTP：最新空库初始化、全部表/字段注释、知识发布并发和生效期、租户/公司/报表撤权、幂等、取消、失租、过期、只读业务边界及历史任务恢复。
- 真实模型与 HTTP MCP：普通多步分析、带否定/区间的同类变体、纯知识回答、无依据、矛盾/过期材料、歧义/不支持操作；保留首次失败、修正次数、最终结果与来源指纹。
- 真实浏览器：提交与进度、刷新恢复、中间结果和展开分页、来源引用、知识编辑/发布/停用、取消及错误恢复。前端生产构建和受影响模块回归必须通过。
- 文档、注释、最新 V1、图表生成器及全部产物同步；执行 `node tools/check-comments.cjs`、`node tools/check-docs-real-model.cjs` 和相关现有门禁。

数据库操作另需用户针对本轮授权。新夹具使用 `analysis_knowledge_it_<UUID>`；复用回归沿用各自专用前缀。每次先记录已有库和准确新库名，测试结束只清理本轮创建目标，保留 `report_demo`、执行前已有库及无关数据。本轮不对运行中的演示库修复 Flyway 校验和或静默清库。
