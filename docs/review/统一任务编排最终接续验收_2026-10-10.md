## 数据与证据口径

真实模型回放只查询、调整选择和准备待确认清单，不点击确认派单。浏览器夹具另行验证原查询、资格核验、取消、查看已取消清单、重新核对、准备、确认、立即刷新恢复、追溯、重复请求拒绝、公司和报表权限、包含与严格数值边界。

浏览器确认前已独立核对执行请求为 0、来源未派单；确认并刷新恢复后，执行请求为 1、目标来源已派单，清单分别为 CANCELLED 和 EXECUTED。该行为只发生于本仓库隔离 Demo 数据，不等于接入真实外部 ERP。

最新浏览器的费用查询持久化展示依次为 `LIST, LIST, DETAIL, LIST, LIST, DETAIL`，匹配数依次为 `2, 3, 1, 3, 1, 1`；[独立 SQL 结果](task-continue-2026-10-10/browser-final-21/final-queries.json)确认费用来源未改变。重复准备已执行目标时，页面明确提示“该候选预览已用于派单，不能重复生成清单”，最终 SQL 仍只有原取消清单、执行清单及一次业务执行请求。金额 `>= 96000` 返回 SO2026001 与 SO2026007，改为 `> 96000` 后仅返回 SO2026001；已经派单的普通业务记录仍可正常只读查询。
