## 实现范围

| 能力 | 本次实现及边界 |
| --- | --- |
| 多查询知识检索 | 原问题、聚焦问题和至多两条模型改写共同参与词项召回，随后由真实模型重排；当前没有向量数据库或向量索引。至多六个知识主题共用一次 `RAG_REWRITE` 和一次 `RAG_RERANK`，全无候选时无需重排。 |
| 结构化输出 | `semantic-rag-2` 使用固定可空字段 `firstQuery`、`secondQuery`，每项至多 300 字符；严格检查主题编号、未知字段、重复字段、来源编号和排列。多余第三项、非法 JSON 或不完整输出使本轮失败，不静默截取、不回退、不增加模型调用预算。 |
| 候选与模型输入 | 至多 24 个唯一候选片段，完整重排输入按 UTF-8 实测限制在 48 KiB，每题最多返回 12 个片段。候选平衡来源，模型传输使用服务器短编号，校验后还原为真实引用编号。命中数、候选数、实际返回数和截断分别说明。 |
| 词项召回边界 | `contentOffset` 区分可召回正文和生成的引用元数据；检索只使用真实标题与正文，报表范围、时间或片段前缀不能制造命中。词典别名仍受租户、公司、报表和版本约束。 |
| 长资料与引用 | 分片保持脱敏后原文的连续子串，按自然边界拆分并限制重叠。每片保留原始来源、版本、适用范围、时间和定位信息；同一文档多个片段不当作多个独立来源计算召回。 |
| 权限与执行版本 | 知识发布版本、规则与词典、当前授权范围、来源协议及执行配置均参与指纹。模型往返后重查权限和知识版本；取消、租约失效、版本变化或不合法计划不得继续发布答案或重放业务查询。 |
| 回答与检索说明 | 原文引用、数值及日期校验通过后再做独立回答复核。覆盖说明只陈述实际检索范围；无命中不能被写成全局不存在制度，未触发别名预算不能被写成预算不足。 |
| 日期与数字 | 公共引用抽取区分普通数值、日历值和时刻。支持已有来源明确提供的日期时间精度及有单位的局部日期范围省略；禁止跨字段、跨来源拼接、自动进位、擅自换算时区，日期组件不能证明金额或数量。来源契约为 `evidence-source-4`。 |
| 比较差额表述 | 公共比较证据同时提供“之后减之前”的有符号差额、方向和绝对幅度。金额使用 `BigDecimal` 并按币种分别处理；计数先转为 `long` 再求差。增、减、零均从完整结果确定生成，不放宽引用正负数门禁，不从预览行重算全集。执行配置版本为 `5`。 |
| 前端状态恢复 | 请求在 POST 前按当前会话保存；刷新、离开返回和历史回填不自动提交。明确点击核对时复用原幂等请求号；历史终态仍可查看，取消后的回填保持只读准备状态，失效快照保持禁止开始分析。 |
| 诊断与用量 | 诊断保留请求/Schema 指纹、参数形状、响应状态、媒体类型、受限正文信息和异常链分类。未观察到 HTTP 响应与已收到错误 HTTP 响应分开；缺失原生用量记为未知，不能填零或据此计算完整成本。 |
