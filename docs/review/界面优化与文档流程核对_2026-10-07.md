# 界面优化与文档流程核对

日期：2026-10-07（Asia/Shanghai）。核对起点为 `87af564`，本报告描述其后的工作区变更；提交前源文件与生成产物共同接受检查，不能仅把起点提交当作本轮实现。

## 本轮范围与边界

完成工作台视觉与中文展示优化、手工派单详情入口修复，并检查全部当前说明文档与十二页流程图对代码的适配。历史设计、评审、截图和实际验收记录保留原日期及结果；修改索引和历史属性说明，不改写当时失败、跳过或通过率。

沿用当前依赖与 `real,mcp`、`agent.semantic.mode=active`、真实模型及认证 HTTP MCP。此次没有修改后端运行逻辑、数据库表结构、启动配置或依赖版本，没有新建、重建或清理数据库，也没有执行派单。账号生命周期问题继续暂缓。真实 ERP、正式外部认证、真实工单系统、容量、灾备及容器部署不在本次完成声明内。

## 工作区实现变更

1. **页面视觉**：统一侧边导航、标题层级、工具栏、按钮、表格、金额对齐、状态标签、弹窗及抽屉；调整登录页、工作台名称和窄窗口布局。移除业务报表标题中的物理表名，保留业务名称、总数、本页数和本页合计。
2. **手工派单记录**：从正文前的常驻列表改为右上角独立抽屉；提供加载、失败提示、分页、结果说明、追溯及原有状态相关操作。手工派单后打开记录抽屉，未知结果仍先核对。
3. **详情交互**：实际浏览器中精确点击旧小箭头可展开，但其周围空白无响应。增加明确的“展开详情／收起详情”按钮、键盘支持和整格点击；原生箭头阻止冒泡，避免双重切换。使用 `planId` 绑定展开状态，同页刷新保留、切页清理，迟到响应不能恢复错误页面的展开标识。
4. **中文展示**：新增共享 `presentation.js` 和 `BusinessLabel.vue`，覆盖状态、业务环节、审计动作、调查工具与控制步骤、字段类型和系统操作者。统一目录、清单、查询及调查卡片的展示；未知代码保留原值，原始标识可查，不改变接口枚举或执行逻辑。
5. **运营治理**：指标卡片和统计说明分层展示；明细支持中文／代码搜索、每页 20 组及有界滚动；报表名称来自当前目录，长版本缩短显示但保留原值。顶部指标继续使用服务端完整汇总，不能从筛选后明细重算。工作台和审计表限制可见高度，时间格式、结果标签及空值说明统一。
6. **回归**：补充状态翻译不混淆未知、已执行与成功的断言；普通业务分组不作为枚举翻译；验证手工记录加载竞态、错误提示、按稳定清单标识保持展开及切页清理。测试加载器接入真实展示函数。
