# P2 有限多步分析与业务知识问答实现与验收

实施开始于 2026-10-11，最终验收于 2026-10-12（Asia/Shanghai）。基线为 `2d5d3da`，本报告记录其后的 P2 工作区变更；操作见[分析与知识问答](../有限多步分析与业务知识问答.md)，目标见[P2 实施计划](../P2有限多步分析与知识问答实施计划_2026-10-11.md)。

本轮完成有限分析图、业务知识版本、任务恢复和页面交互。最后完整回归 Java 实际执行 1,128 项、前端 200 项、评估工具 21 项通过。P2 专项 19 项数据库/状态机、7 项真实模型场景及最终浏览器夹具通过；48 项分析纯逻辑测试已包含在 Java 总数中，不重复相加。复用 P1 专项实际执行 13 项通过，2 个独立真实模型/浏览器入口条件跳过。

## 实现行为

| 能力 | 已实现的行为与边界 |
| --- | --- |
| 有限分析图 | 一家公司、一张授权报表；QUERY、SNAPSHOT、GROUP、RANK、DRILLDOWN、COMPARE、KNOWLEDGE 七类只读步骤；至多六步、两个基础查询/快照 |
| 规划与复核 | 真实模型提出计划，程序严格验证字段、类型、范围、前序引用和展开路径，再独立复核；不允许 SQL、任意工具或业务写入 |
| 确定性分析 | 复用完整查询快照和 P1 精确十进制计算；分组和排名使用完整集合，明细展开保持原快照、大小写、尾随空格、空值及币种边界 |
| 回答依据 | 实际编号枚举约束输出；模型选择引用，程序回填原文并校验数字，独立模型复核语义；明确有依据、依据不足和资料冲突 |
| 知识资料 | 目录、字段、业务词典、有效规则与管理员制度；按租户/公司/报表和生效期过滤；草稿、显式发布、停用、不可变历史及乐观版本保护 |
| 异步任务 | 本人任务和请求幂等，令牌租约、取消撤销回写权、失租中断、有限留存；刷新和明细翻页只读取原任务 |
| 页面 | 分析与问答、知识管理、查询快照入口；进度、中间结果、完整明细、原文引用、版本与失效提示 |
| 最新结构 | 新增知识文档、知识历史和分析运行三张表，共 47 张业务表、557 个字段；V1、注释清单、数据库字典和十五页图表同步 |

总模型预算八次、整轮 180 秒、单次传输 40 秒、请求体 128 KiB、回答依据 80 KiB、持久步骤 512 KiB。每实例两个工作线程，同用户两个/同租户八个活动任务，本人最多五十项、保留二十四小时。模型与 HTTP 调用不占用认领事务；发布及读取继续重查权限、目录/词典/规则/知识指纹和原快照完整性。

## 失败与共同修复

| 失败事实 | 根因与修复 |
| --- | --- |
| 规划与复核对展开来源、分页含义理解不同 | 共享操作契约与程序验证的展开路径；明确查询首屏大小不限制完整快照 |
| 尚未检索就提前判定知识不足 | 规划与复核读取同一授权范围的有界预览，实际 KNOWLEDGE 步骤执行后再判断依据 |
| 长引用抄写和跨步骤数值引用不稳定 | 模型只选真实编号，服务器回填原文；原生枚举、逐项数字校验与真实候选提示，不自动补引或放行 |
| 首次浏览器复核把完整集合与选集误作矛盾、否认分页入口 | 明确每步统计所属集合；回答与复核使用共同实际展示证据 |
| 独立展示上下文暴露 0 起点内部序号且无法引用 | 回答只接收页面从 1 开始的编号；每个行步骤的分页说明进入该步骤的引用原文 |
| 可读摘要曾把 Summary record 强转为 Map | 按真实类型读取并增加精度、完整计数与页面说明回归 |
| 午夜知识依据日期切换导致 409 | 保留跨日保护和原始失败，在新日期重新发起并复验；没有冻结或绕过生产日期 |
| 终态显示 FINISHED，取消后旧步骤仍显执行中 | 按运行终态投影未完成步骤；空展示使用空值合并，不回退内部状态码 |
| 比较证据与异常收尾边界 | 按真实列类型处理嵌套 before/after，限制证据预览；意外错误结束已开始步骤，迟到响应不获回写权 |
| 浏览器夹具 stop 曾直接计通过 | 改为必须明确 accepted=true；中止不计通过。加载中采集与旧闭包路径等取证问题单独分类 |

所有轮次见[证据索引](p2-analysis-knowledge-2026-10-12/evidence-index.json)，修复前原件未覆盖。运行日志部分中文因 Windows 控制台编码显示异常，结构化 JSON 可读；未改写旧日志来伪装原始输出。
