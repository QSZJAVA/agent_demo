## 正文语义审查与评分口径

本次代码语义审查覆盖全部七类受控状态说明及四类待查说明：明确失败与未知分开；远端成功必须保留本地待核对限定；NOT_FOUND 不推断未发送或允许重发；规则存在不证明因果；证据缺失与无法判断不伪装为已核实。固定摘要明确调查只读，待查说明只表达仍需核查的方面。模型收集阶段自由文本不进入最终报告。

这是代码及受控文案审查，不是新增的外部人工审查结论。当前版本不输出开放式自然语言因果解释，因此不能用本次正文指标声称具备任意解释的正确性。业务错误细节可从实际引用证据查看。

第 3 版评分器不调用生产校验器或正文生成器自评。每次归档 `assessment`，汇总保留：

- `correctItems / expectedItems`：正确条目数 / 应判定条目数；没有报告或漏项仍计入分母。
- `supportedFacts / assertedFacts`：符合语料和证据且正文一致的展示断言数 / 实际展示断言数；固定摘要、逐项解释和每项待查说明分别计数，不声称是任意自然语言原子命题计数。
- `legalCitations / totalCitations`：实际取得且归属合法的引用数 / 展示引用数；引用重复、跨条目或不存在均判错。

成功率还要求逐项原因、核实程度、必要远端查询及建议合法；单一指标不能抵消错误。原第 2 版 47/48 只作为历史分类和引用评分证据，不与本次直接比较。新批次的真实模型名称、预算及实际编译产物摘要以各自 manifest 为准。
