# 统一聊天知识问答与分析接续实现与验收

日期：2026-10-13。状态：实现及本轮验收完成；最终修复版全仓程序回归、23 项数据库/HTTP 联合用例及真实浏览器验收均已通过。本文只记录已经结束且有证据的执行，不将提交、远端核对或未执行的生产准入计为测试通过。原始时间保留 UTC；本文所称日期采用 Asia/Shanghai。

本轮把业务知识问答与有限多步分析接入同一聊天入口，支持从成功业务查询继续分析原快照，并补齐聊天接收回执、断流核对、历史消息补写和旧请求迟到的隔离。真实链路采用 `real,mcp`、`agent.semantic.mode=active`、实际模型 `deepseek-v4.1-flash`、真实模型认证请求及 HTTP MCP 业务服务。测试数据、知识资料和用户来自已授权的本仓库专用隔离库；没有接入外部 ERP、真实工单或外部认证系统，也没有完成生产容量、灾备与部署准入验收。

原始归档入口为 [copy-manifest.json](D:/demo-v1/demo/docs/review/unified-chat-analysis-2026-10-13/copy-manifest.json)。每份复制文件记录来源路径、归档路径、字节数及两端 SHA-256；归档使用 `-text` 保留原字节。失败日志保留原内容，后续修复和复测分别记录。各批次存在大量重复覆盖，不能相加作为独立测试数量。

**实现与契约**

| 能力 | 当前实现与不可扩大的边界 |
| --- | --- |
| 统一语义路由 | 延用独立目标、完整计划、业务预检、独立复核及有界修正，增加 `KNOWLEDGE`、`ANALYSIS`。没有另设关键词路由。模型只选择授权范围、模式和服务器提供的来源引用；外层将完整用户原文绑定为分析问题。 |
| 明确的读取模式 | `Request.mode` 必填。`KNOWLEDGE_ONLY` 只允许知识步骤、不得携带快照；`SNAPSHOT_ONLY` 必须绑定原快照，只允许快照、分组、排名、展开和知识步骤，禁止查询当前数据及集合比较；`CURRENT_DATA` 允许原有限只读图，显式快照可参与与当前数据的比较。模式参与幂等摘要、动态 Schema、全图校验、逐步执行和恢复校验。 |
| 原查询接续 | 只从当前成功业务查询焦点取得同用户、单公司、单报表、完整且有效的来源。授权、查询定义、快照数量及序号均重新核验；过期、缺行或错误引用不能改成读取当前数据。模型得到不透明来源引用，不能指定任意快照标识。 |
| 可靠接收 | HTTP 聊天要求发送前保存的稳定 `Idempotency-Key`。新会话与 `chat_turn_receipt` 同事务创建；本人同键同完整输入回放，异输入返回冲突。首次输入中的空会话标识、预览、排除集合和结构化编辑保持原值参与核对。 |
| 分阶段恢复 | 模型前保存 `PLANNING`；复核后在原会话租约下保存完整可信请求及范围、配置指纹形成 `READY`，随后以 `analysis-<requestId>` 原子创建子任务、关联回执及任务卡片。只有明确核对才恢复原提交；GET 不调用模型、不重新查询、不创建任务。失租且无可信方案的规划只能显示中断，不能自动重新解释。 |
| 永久失效与瞬时故障 | 可读取的 READY 回执在冻结依据永久失效时，GET 只读投影失败，明确核对后结束原回执；配额和瞬时服务故障保留核对能力。回执本身过期或权限变化仍按读取边界拒绝，不能重新建会话。 |
| 迟到旧轮次 | 旧 READY 的失败只更新原请求回执。后来成功查询的阶段、焦点、未决标志、查询引用及快照不得被旧请求改写；不能通过清空后来状态来结束旧请求。 |
| 卡片与历史权限 | `analysis_task` 仅保存轮次、任务、模式、公司和报表五字段引用。恢复逐次核对原会话、原子请求号、完整请求及双方指纹；历史载荷不作为可信答案。失效卡片清空内容，删除会话后独立分析详情也拒绝读取。 |
| 历史投影就绪 | 回执必填 `historyReady`。终态不代表历史消息已完成展示表补写；存在待投影消息时，前端保留原结果与请求号，仅 GET 等待，完成后按持久化消息标识恢复历史。真实行锁导致 `SKIP LOCKED` 的场景已纳入联合验证。 |
| 页面恢复与答案期限 | 发送前保存并回读完整请求，首帧或尾帧缺失时按原键找回会话。明确核对才 POST 原输入。任务答案展示最多 30 秒，之后撤下并重新核权；身份切换、隐藏、离页、取消及迟到响应都有状态保护。 |
| 留存与可追溯性 | 回执到期清理可信正文和恢复摘要，保留最小防重身份；会话删除清理关联子分析，原空会话输入也不能借旧键重建。数据库、模型调用、HTTP MCP、截图及浏览器行为分别取证，不以其中一类替代其他验收。 |

Demo 自带账号和会话的既有维护范围保持原约定；本轮没有升级前端依赖或增加历史协议兼容。业务租户、公司、报表权限、服务间认证、用户确认、幂等和执行版本保护仍然有效。
