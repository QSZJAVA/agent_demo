# 查询工作区与日常分析

当前链路为 `real,mcp`、`agent.semantic.mode=active`，真实模型 `deepseek-v4.1-flash` 使用原生 JSON Schema、thinking 关闭，业务读取经过认证 HTTP MCP。自然语言的新目标或条件变化仍执行独立目标判断、规划、业务预检与完整复核。查询工作区承接已经取得的完整事实，用明确的按钮和参数完成日常操作。

## 查询、分页和常用条件

在业务助手完成查询后，点击“打开查询工作区”，或点击卡片的上一页、下一页。工作区绑定查询运行编号与页码，刷新后恢复同一位置。分页重新校验当前权限和业务定义，读取原快照，不再次调用模型或读取来源。聊天保留原来展示的记录引用，工作区翻页不会把未展示给会话的记录偷偷加入模型上下文。

每份快照保留原查询、列定义、完整有序匹配集、按币种统计、观测时刻、有效期、内容摘要及实际进入共同筛选的记录数。销售等本地来源使用同一次 `REPEATABLE_READ` 事务；工单按来源观测时点保存，不能解释为跨系统同时快照。工单“查看快照进度”展开该快照的步骤，当前提供者仍是明确标注的演示流程，不执行审批或推进流程。

快照默认保留 24 小时。过期、权限指纹变化、目录或业务词典发布、明细缺失时明确拒绝继续读取。中间缺行不能由下一页补齐。重新读取按钮仍读取这份快照；需要最新来源事实时，重新运行常用查询或在助手中明确发起新查询。

“保存为常用查询”保存私人定义与业务口径，不保存永久授权。支持两种日期方式：

- 固定条件和日期：下次运行保留当前日期边界。
- 每次重算上个自然月：用户明确选择日期字段，执行时按 `Asia/Shanghai` 重新计算上月，替换该字段原有日期条件，保留其他字段限制。例如 2026-10-11 执行时使用 2026-09-01 至 2026-09-30。

常用查询可以重新运行、重命名、删除；更新和删除带定义版本，旧页面不能覆盖新的编辑。重新运行访问真实 HTTP MCP 并重新授权，得到新的运行编号。公司范围或业务口径已经变化时，应重新查询并保存。删除定义不删除来源业务或已经保存的快照。

## 指标、期间和对比

指标分析在完整快照上计算，支持最多三个分组维度、记录数、金额合计、均值及按日/月趋势。金额按声明的币种分开，使用精确十进制；均值只包含有金额的记录，四舍五入至六位小数。缺少金额、币种或日期分别计数，不把缺失事实改成零。超过 500 组时拒绝整次计算，不能截断后冒充完整统计。

按月趋势可选择比较月份。同比/环比只用于查询范围完整覆盖且已结束的本期、上月、去年同月；三段期间使用相同业务限制。日期无法归属、比较期间缺少金额或币种时不生成增长率。完整期间无记录可为零，但基期金额为零或负数时增长率显示“不可计算”。本期金额、上月金额和去年同月金额仍可核对。当前指标不包含未经定义的税额、逾期天数或外部 ERP 口径。

查询对比返回两份快照的新增、移除、字段变化和按币种金额差额。显示两次观测时刻；条件、公司范围或业务定义不同会明确提示只能解释为集合差异，不能当作业务增长。全部变化参与计数，最多展示前 100 条明细；数值尺度差异不会被误认为金额变化，空值与零仍有区别。

## 完整结果导出

点击“导出完整结果”创建异步 CSV 任务，使用完整快照而非当前展示页。任务保留同一请求键；丢失响应后再次点击会恢复原任务，只有失败或取消后显式“重新生成”才创建新的请求。

任务可从工作区刷新状态，也可从“我的任务 → 查询导出”恢复、取消或下载。下载逐次重新检查身份、公司、报表、业务定义及快照有效期，不提供公开分享链接。UTF-8 CSV 含来源、观测时间、有效期和完整匹配数。所有单元格包括标题与元数据统一使用单引号文本前缀，避免公式执行及长编号、金额被表格软件自动改写；空值保持为空。CSV 不具备可靠的数值类型声明，导入其他系统前应按明确字段契约处理文本前缀。

导出队列保存状态、认领令牌和租约。取消、到期或失租后，旧工作线程不能回写完成结果；失租最多重新认领三次，每次重建同一快照文件。生成超时、队列超时和体积超限均给出失败状态。服务恢复不会自动确认派单或修改业务数据。

## Top N 与明确确认

“Top N 候选”要求用户选择字段、方向及 1–50 条的明确数量。排名使用完整授权快照，空值在末尾，并列按稳定业务标识排序；非空记录不足时要求调整数量，不自动少取。金额排名要求唯一已声明币种，不跨币种比较大小。

查看排名是只读操作。只有点击“为这 N 条生成待确认清单”才进入既有预览与清单流程；准备时重读当前来源、规则与字段，排名或候选事实改变会要求重新查询，不静默替换对象。相同快照和排名参数重放时恢复原清单。清单仍须用户显式确认，执行继续检查权限、租约、规则、全部确认字段和执行版本。刷新、打开提醒、查看调查均不会确认或重发。

这一入口是结构化的有界排名能力。聊天中的自然语言候选选择仍遵守原有指代、完整性和语义契约，不因存在 Top N 按钮而跳过复核。

## 任务与站内提醒

“我的任务”统一列出待确认清单、需处理异常、派单任务、异常调查及查询导出。任务编号和创建时间用于区分同类历史运行。各类任务保留自己的状态机；提醒按对象与状态版本去重，轮询和续租不产生新提醒。标记已读时再次核对用户实际见过的状态摘要；新状态不会被旧页面顺带标成已读。

待确认清单即使尚未提交执行任务也可在此找回。本人详情支持核对并确认、查询已有结果，以及复核确认后重试明确失败项；关窗、切换清单或登录状态变化会使尚未提交的旧确认失效。结果未知先核对，不自动认定失败。调查提醒打开用户所选的历史调查编号，不自动切到最新调查或重新发起分析。报告与引用证据继续分别说明已证实事实和未核实事项。

## 接口与预算

所有接口位于 `/api/query-workspace`，用户身份来自认证会话，不接收模型或表单指定租户、账号或管理员身份。

| 操作 | 接口 |
| --- | --- |
| 最近快照、稳定分页、主动失效 | `GET /runs`、`GET /runs/{id}?page=...`、`DELETE /runs/{id}` |
| 保存定义、列出、重新运行 | `POST /runs/{id}/saved`、`GET /saved`、`POST /saved/{id}/run` |
| 定义版本更新、删除 | `PUT /saved/{id}?version=...`、`DELETE /saved/{id}?version=...` |
| 指标、排名、准备清单 | `POST /runs/{id}/analysis`、`POST /runs/{id}/rank`、`POST /runs/{id}/rank-plan` |
| 两次查询对比 | `GET /compare?before=...&after=...` |
| 提交与恢复导出 | `POST /runs/{id}/exports`（稳定 `Idempotency-Key`）、`GET /exports/{id}` |
| 取消与受控下载 | `POST /exports/{id}/cancel`、`GET /exports/{id}/file` |
| 提醒筛选及已读 | `GET /inbox`、`POST /inbox/read` |

默认预算：来源最多 100000 条、120 秒及 16 MiB 事实；每页最多 50 条，页码最多 100000。每人最多 128 份有效快照、64 MiB 有效事实，每租户 256 MiB；常用查询最多 100 项。导出每人最多 4 个在途任务、租户 32 个，每人每天最多 100 次；文件最多 32 MiB，单次生成最多 120 秒，任务创建后超过 10 分钟仍未完成会失败。上述值是保护上限，不是生产容量承诺。

标准来源只将有真实 JDBC 类型证明的条件参数化下推，保留共同 Java 谓词完整校验；派生字段、无法证明等价的映射和字符串范围比较仍在有界集合中计算。AND/OR、空值、十进制、大小写与尾随空格保持原语义。界面中的“进入筛选”计数是应用收到的记录数，不等同数据库物理扫描行数。

最新 V1 为 44 张业务表、512 个字段，新增快照、常用定义、导出队列及已读状态。当前不提供历史数据迁移；既有 `report_demo` 不会自动重建或修复校验和。本轮使用明确授权的专用隔离库验证。实施范围见 [P1 计划](P1查询工作区实施计划_2026-10-11.md)，分层结果见 [P1 验收报告](review/P1查询工作区实现与验收_2026-10-11.md)。正式外部认证、真实 ERP/工单、生产容量、部署及灾备仍需实际环境验收。
